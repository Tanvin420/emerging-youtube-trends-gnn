# Centrality-Guided Neural Graph Attention for Predicting Emerging YouTube Trends

**Accepted at the 29th International Conference on Computer and Information Technology (ICCIT 2026),
18-20 December 2026, Cox's Bazar, Bangladesh** (to appear in IEEE Xplore).

> S. R. R. Rahman, J. U. Tanvin, A. B. I. Shoeb, M. N. Islam, and N. Sharmin,
> "Centrality-Guided Neural Graph Attention for Predicting Emerging YouTube Trends,"
> in *Proc. 2026 29th International Conference on Computer and Information Technology (ICCIT)*, Cox's Bazar,
> Bangladesh, 2026.

This repository contains the official code, all result files, and the figures for the paper. We build one
keyword-similarity graph per day and region from YouTube trending lists, describe each video by its graph centralities,
view count, category, and text embedding, and ask whether graph neural networks can predict which videos will be
structurally influential on the next days. Every number in the paper's tables and figures can be traced to a file in
`results/`.

The paper itself is not included here; a link will be added once it is published in IEEE Xplore.

## Main findings

All numbers are on the 2022 test period at horizon *t*+1, mean over three seeds unless marked.

| Finding | Evidence |
|---|---|
| Predicting whether a video is in the top 20% of the **Structural Influence Score (SIS)** tomorrow is dominated by persistence. | Persistence has the highest status F1 (0.836); learned models win only on ranking (AUC up to 0.968 vs. 0.961). |
| On the harder **emergence** task (videos not yet in the top 20%), GraphSAGE is best. | Emergence F1: GraphSAGE 0.373, SP-CGA-GAT 0.360, MLP 0.331, CGA-GAT 0.182. GraphSAGE's lead over SP-CGA-GAT is significant (paired day-level bootstrap, 95% CI of the F1 difference [0.008, 0.019]). |
| CGA-GAT failed because its layer had no self-preservation path; adding a GraphSAGE-style self-transform (SP-CGA-GAT) fixes it. | Emergence F1 0.182 → 0.360; status F1 0.815 ± 0.003 vs. GraphSAGE 0.810 ± 0.002. Removing the centrality bias from SP-CGA-GAT gives similar results (SP-GAT: 0.810 / 0.362). |
| Centrality explains most of what is predictable for SIS, partly by construction (SIS is built from the same centralities). | Dropping centrality costs 0.19-0.23 F1. On a graph-independent **view-count** target, centrality alone is near chance (AUC 0.581), while SP-CGA-GAT still beats the MLP (F1 0.896 vs. 0.875). |
| One global decision threshold over-predicts positives for India; a per-region threshold fixes it. | Overall F1 +0.009, India precision +0.107; other regions unchanged within seed variance. |
| Self-preservation also holds up in zero-shot transfer to data from 2017-18 and 2025-26. | AUC of CGA-GAT 0.916 → 0.633 vs. SP-CGA-GAT 0.963 → 0.886 (2018 → 2026). |


Large intermediate files (`data_cache/`, about 2.8 GB) and raw data are not stored in the repository; they are
regenerated by the pipeline.

### Source files (`source_code/`)

| File | Purpose |
|---|---|
| `config.py` | Paths, regions, split dates, hyper-parameters (all models share one configuration). |
| `data_prep.py` | Loads raw CSVs, cleans text, builds one record per video and day. |
| `text_utils.py` | Lower-casing, URL/number/punctuation removal, English stop words, WordNet lemmatisation. |
| `keyword_extraction.py` | Top-15 TF-IDF keywords per video, fitted separately for each daily snapshot. |
| `graph_construction.py` | Daily keyword-overlap graphs (edge if two videos share a keyword, weight = Jaccard similarity). |
| `centrality.py` | Degree, closeness, betweenness, eigenvector centrality, min-max normalised per snapshot, plus day-over-day deltas and SIS. |
| `sis_labels.py` | Top-20% SIS labels. |
| `view_labels.py` | Top-20% view-count labels (graph-independent target). |
| `embeddings.py` | `all-MiniLM-L6-v2` sentence embeddings of title, description, and tags. |
| `channel_graph.py` | Same-channel co-trending edges (second edge type). |
| `build_dataset.py` | Assembles PyTorch Geometric snapshots with features, status and emergence labels for *t*+1..3. |
| `models.py` | MLP, GCN, GraphSAGE, GAT, CGA-GAT, GAT-Res, CGA-GAT-Res, SP-CGA-GAT, SP-GAT, Dual-SP-CGA-GAT. |
| `train_eval.py` | Temporal split, training loop (Adam, early stopping on validation F1), metrics. |
| `persistence_baseline.py` | Persistence and Trend/Momentum baselines. |
| `xgb_baseline.py` | XGBoost baseline (three seeds). |
| `run_experiments.py` | All experiments of the paper (one function per experiment, see below). |
| `graph_randomization.py` | Degree-preserving rewiring of every snapshot. |
| `threshold_calibration.py` | Per-region decision thresholds chosen on the validation set. |
| `calibration_metrics.py` | Brier score and expected calibration error. |
| `significance.py` | Paired bootstrap over test days. |
| `prepare_external_dataset.py` | Downloads and converts the 2017-18 dataset (Era 2018). |
| `prepare_external_dataset_2026.py` | Converts the 2025-26 dataset (Era 2026). |
| `cross_dataset.py` | Zero-shot evaluation on both external eras and the cross-era summary. |
| `make_figures.py`, `graph_visualization.py` | Figures. |
| `emerging_videos.py` | Case-study list of emerging videos (`results/emerging_videos.csv`, not used in the paper). |
| `backfill_spcga_gat.py` | Adds SP-CGA-GAT to result files created before the model existed. |
| `revision_checks.py` | CPU-only checks (no GPU needed): reproduces the persistence baselines, the view-count persistence baseline, split sizes, and graph sizes. |

## Installation

Tested with Python 3.11, PyTorch 2.11 with CUDA 12.8, and an NVIDIA RTX 5090. A GPU is recommended for the neural
models; the data-preparation steps and `revision_checks.py` run on CPU.

```bash
git clone https://github.com/Tanvin420/emerging-youtube-trends-gnn.git
cd emerging-youtube-trends-gnn
conda create -n cga-gat python=3.11 && conda activate cga-gat
# install PyTorch for your CUDA version first: https://pytorch.org/get-started/locally/
pip install -r requirements.txt
```

NLTK stop words and WordNet are downloaded automatically on first use. All commands below are run from the repository
root.

## Data

The three datasets are public but too large for this repository (several GB of raw CSV). Download them and place the
files as described.

| Role | Dataset | Period used | Regions | Link |
|---|---|---|---|---|
| Training, validation, test | YouTube Trending Video Dataset (updated daily), rsrishav | 2020-08-12 to 2022-05-29 | US, GB, CA, IN | https://www.kaggle.com/datasets/rsrishav/youtube-trending-video-dataset |
| Zero-shot, Era 2018 | Trending YouTube Video Statistics, Mitchell J (datasnaek) | 2017-11-14 to 2018-01-05 | CA, DE, FR, GB, US | https://www.kaggle.com/datasets/datasnaek/youtube-new |
| Zero-shot, Era 2026 | YouTube Trending Dataset (updated daily), sheb1lmsp | 2025-12-10 to 2026-09-14 | CA, DE, FR, GB, IN, US | https://github.com/sheb1lmsp/youtube-trending-analytics (Kaggle mirror: https://www.kaggle.com/datasets/shebilmsp/youtube-trending-dataset-updated-daily) |

**1. Primary dataset.** Put `US_youtube_trending_data.csv`, `GB_youtube_trending_data.csv`,
`CA_youtube_trending_data.csv`, and `IN_youtube_trending_data.csv` in `dataset/`. The Kaggle dataset kept growing after
our download, and the code does not filter dates, so trim newer copies to the period used in the paper:

```python
import pandas as pd
for r in ["US", "GB", "CA", "IN"]:
    p = f"dataset/{r}_youtube_trending_data.csv"
    d = pd.read_csv(p, low_memory=False)
    t = pd.to_datetime(d["trending_date"], utc=True, errors="coerce")
    d[(t >= "2020-08-12") & (t <= "2022-05-29")].to_csv(p, index=False)
```

**2. Era 2018.** `python -m source_code.prepare_external_dataset` downloads a public mirror of the Kaggle data into
`dataset/external_2018/` and writes `dataset/{CA18,DE18,FR18,GB18,US18}_youtube_trending_data.csv`.

**3. Era 2026.** Fetch the six countries with a sparse checkout, then convert:

```bash
git clone --filter=blob:none --no-checkout --depth 1 \
    https://github.com/sheb1lmsp/youtube-trending-analytics.git dataset/external_2026/repo
cd dataset/external_2026/repo
git sparse-checkout init --cone
git sparse-checkout set data/videos/country=US data/videos/country=GB data/videos/country=CA \
    data/videos/country=IN data/videos/country=DE data/videos/country=FR
git checkout main
cd ../../..
python -m source_code.prepare_external_dataset_2026
```

This source is updated daily; keep only 2025-12-10 to 2026-09-14 (same snippet as above with the 2026 file names and
dates) to match the paper. The 2026 files have no description field and list the top 50 videos per day, so their graphs
are sparser.

## Reproducing the results

Each stage caches its output in `data_cache/`.

```bash
# 1. Features and graphs for the primary dataset
python -m source_code.data_prep
python -m source_code.keyword_extraction
python -m source_code.graph_construction
python -m source_code.centrality
python -m source_code.embeddings
python -m source_code.build_dataset

# 2. Main comparison (all neural models, t+1)
python -m source_code.run_experiments

# 3. XGBoost baseline (prints three-seed results for both tasks)
python -m source_code.xgb_baseline
```

The remaining experiments are functions in `run_experiments.py`:

```python
from source_code import run_experiments as rx
rx.run_horizon_experiment()                                    # t+1, t+2, t+3
rx.run_centrality_ablation(horizon=1)                          # centrality as feature vs. in attention
rx.run_feature_ablation_hierarchy(horizon=1)                   # MLP feature groups, status task
rx.run_feature_ablation_hierarchy(horizon=1, mask_attr="emerge_mask1")   # emergence task
rx.run_graph_randomization_check(horizon=1)                    # real vs. rewired graphs, status task
rx.run_graph_randomization_check(horizon=1, mask_attr="emerge_mask1")    # emergence task
rx.run_emergence_comparison(horizon=1)
rx.run_channel_augmentation_experiment()                       # Dual-SP-CGA-GAT
rx.run_regional_calibration_experiment()
rx.run_calibration_diagnostics()                               # Brier score, ECE
rx.run_significance_test()                                     # SP-CGA-GAT vs. GraphSAGE, emergence
rx.run_selfpreservation_ladder()                               # SP-GAT
rx.run_view_popularity_experiment()                            # graph-independent target
rx.run_survivorship_correction_experiment()                    # departed videos as negatives
rx.run_percountry_comparison()                                 # one model per country
```

```bash
# 4. Zero-shot evaluation on Era 2018 and Era 2026 (after preparing both, see "Data")
python -m source_code.cross_dataset

# 5. Figures and CPU-only checks
python -m source_code.make_figures
python -m source_code.graph_visualization
python -m source_code.revision_checks
```

## Glossary

| Term | Meaning in this work |
|---|---|
| Daily snapshot | One graph per day and region; nodes are the videos on that day's trending list (about 200). |
| Keyword-overlap graph | Two videos are linked if they share at least one of their 15 top TF-IDF keywords; the edge weight is the Jaccard similarity of their keyword sets. |
| TF-IDF | Term frequency-inverse document frequency; scores how characteristic a word is for one video compared with the other videos of the same day. |
| Jaccard similarity | Size of the intersection of two keyword sets divided by the size of their union. |
| Degree, closeness, betweenness, eigenvector centrality | Four standard measures of how central a node is: number of neighbours, closeness to all other nodes, how often it lies on shortest paths, and connection to other central nodes. |
| Structural Influence Score (SIS) | Mean of the four centralities after min-max normalisation within the snapshot. It measures structural position, not views. |
| Status task | Predict whether a video will be in the top 20% of SIS at *t*+*h*. |
| Emergence task | The same prediction, restricted to videos that are not in the top 20% today; about 4.2% of them enter it the next day. |
| Persistence baseline | Predicts that today's top-20% status stays the same; it scores by today's SIS. |
| Trend/Momentum baseline | Ranks videos by their mean day-over-day change in centrality. |
| Message passing | How a GNN updates a node by aggregating representations of its neighbours. |
| CGA-GAT | Graph attention network whose attention scores receive a learned bias from the neighbour's centrality. |
| Self-preservation / self-transform | Keeping a node's own representation through a separate weight matrix (as in GraphSAGE) instead of replacing it with its neighbours' average. SP-CGA-GAT adds this to CGA-GAT. |
| Over-smoothing | Node representations becoming indistinguishable after repeated neighbour averaging. |
| Degree-preserving rewiring | Randomly swapping edge endpoints so that every node keeps its degree; it destroys the real wiring while keeping graph size and degree distribution. |
| Zero-shot evaluation | Applying models trained on 2020-22 data to the 2018 and 2026 datasets without retraining or recalibration. |
| PR-AUC | Area under the precision-recall curve; more informative than ROC-AUC when positives are rare. |
| P@k | Precision of the *k* top-ranked videos, with *k* equal to the number of true positives. |
| Expected calibration error (ECE) | Average gap between predicted probabilities and observed positive rates, computed over 10 probability bins. |
| Regional calibration bias | One global 0.5 threshold over-predicting positives for one region (India) because its predicted probabilities are inflated relative to its positive rate. |
| `pos_weight` | Weight on positive examples in the binary cross-entropy loss (4, the 4:1 class ratio of the status task). |

## Reproducibility notes

- **Split.** Training until 2021-11-30, validation 2021-12-01 to 2022-01-15, test afterwards, per region.
- **Seeds.** Multi-seed results use seeds 42, 7, and 123 and report the population standard deviation.
  GAT-Res and CGA-GAT-Res in Table II and all horizon results in Fig. 2 are single runs (seed 42).
- **GPU non-determinism.** Scatter/`index_add_` operations on CUDA are not deterministic, so re-running gives small
  differences (typically below 0.003 F1). Deterministic mode was over ten times slower and was not used.
- **No per-model tuning.** All neural models share the configuration in `config.py`; XGBoost uses fixed settings
  (500 trees, depth 6, learning rate 0.05, early stopping on validation log-loss, `scale_pos_weight` = negative/positive
  ratio).
- **Merged results.** The XGBoost rows were added to `main_comparison_h1.json` and `emergence_comparison_h1.json` from
  `xgb_baseline.py`, and `sage_results.json` holds three-seed GraphSAGE runs made with
  `run_experiments._multi_seed_eval("sage", ...)`.
- **Zero-shot coverage.** GraphSAGE and XGBoost were not included in the cross-era runs (`cross_dataset.MODELS`).
- **Known issue.** In `build_dataset.py`, the survivorship-corrected mask `emerge_mask_all{h}` also includes the last
  day of each region, which has no *t*+*h* snapshot, and counts its videos as negatives (638 extra test nodes, about
  0.75%). This affects only `survivorship_correction_h1.json` and changes its F1 by roughly 0.002.
